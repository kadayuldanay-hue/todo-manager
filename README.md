
# To-Do Manager

## Цель проекта
Разработать простое консольное приложение на Python для управления задачами.

## Состав команды
- Участник 1: Product Owner, Scrum Master, разработчик.
- Участник 2: разработчик, ревьюер, тестировщик.

## Функциональность
- Добавление задач.
- Просмотр списка задач.
- Отметка задачи как выполненной.
- Удаление задач.

## Как запустить
1. Установить Python 3.
2. Скачать файл `app.py`.
3. Выполнить команду `python app.py`.

## Правила Git
- `main` — стабильная версия.
- `develop` — интеграционная ветка.
- `feature/<номер-задачи>-<краткое-описание>` — ветки задач.
- Прямые коммиты в `main` запрещены.
- Изменения принимаются через Pull Request в `develop`.

## Формат коммитов
- `feat:` — новая функциональность.
- `fix:` — исправление ошибки.
- `docs:` — документация.
- `test:` — тесты.
- `refactor:` — улучшение кода без изменения функциональности.
